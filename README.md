# I Love You ❤️

A simple Python project that uses the Turtle graphics library and mathematical equations to create a heart-shaped pattern with the text "I Love Python".


## Features

- Creates a heart-shaped design using mathematical equations
- Uses Python Turtle for drawing and animation
- Displays "I Love Python" as part of the visual pattern

## Technologies Used

- Python
- Turtle Graphics
- Math

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Run the Python file.
4. The Turtle graphics window will display the heart pattern.

## Purpose

A small creative Python project combining programming, mathematics, and visual design.
